# Sistema de Control de Recepción y Salida de Mercadería

Proyecto realizado para la materia **Algoritmos y Estructuras de Datos III**.

## Descripción

Sistema destinado al control de la mercadería que ingresa y sale del sector de recepción de un depósito de bebidas.

Permite registrar los movimientos de mercadería, controlar las existencias disponibles y consultar el historial de ingresos y salidas.

## Tecnologías utilizadas

- Python
- CustomTkinter
- JSON para el almacenamiento de datos
- Git
- GitHub

  ómo obtener e iniciar el proyecto

1. Clonar el repositorio

Abrir una terminal y ejecutar:

git clone URL_DEL_REPOSITORIO
https://github.com/Ana2026O/sistema-de-ctrol-mercaderia.git

2. Ingresar a la carpeta del proyecto

cd NOMBRE_CARPETA_DEL_REPOSITORIO

3. Instalar la dependencia

python -m pip install customtkinter

4. Ejecutar el sistema

python main.py

Se abrirá la pantalla de inicio de sesión del sistema.

## Funcionalidades

El sistema permite:

- Iniciar sesión como administrador.
- Registrar ingresos de mercadería.
- Registrar proveedores desde el formulario de ingreso.
- Seleccionar productos y consultar sus categorías y subcategorías.
- Registrar salidas de mercadería indicando el motivo.
- Actualizar automáticamente el stock disponible.
- Consultar el stock de productos.
- Consultar el historial de movimientos.
- Gestionar productos.
- Gestionar categorías y subcategorías.
