Sistema de Control de Recepción y Salida de Mercadería
Proyecto realizado para la materia Algoritmos y Estructuras de Datos III.

Descripción
Sistema destinado al control de mercadería que ingresa y sale del sector de recepción de un depósito de bebidas.

Tecnologías utilizadas
Python
CustomTkinter
Git
GitHub

El sistema permitirá:

Registrar ingresos de mercadería.
Registrar salidas de mercadería.
Consultar stock disponible en recepción.
Consultar historial de movimientos.
Gestionar productos y proveedores.
